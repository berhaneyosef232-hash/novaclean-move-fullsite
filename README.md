
# NovaClean & Move – Website

Next.js 14 + Tailwind + Nodemailer (IONOS)

## Start
```bash
npm install
cp .env.example .env.local   # trage dein SMTP-Passwort ein
npm run dev
```
→ http://localhost:3000

## Deploy auf Vercel
- Projekt auf GitHub pushen ODER ZIP bei https://vercel.com/new hochladen
- Domain `novaclean-move.ch` in Project → Settings → Domains hinzufügen
